# DzCoinEren

Professional Telegram Mini App rewards platform.

## Current foundation
- React + TypeScript + Vite
- Tailwind CSS
- i18next
- Zustand
- Supabase-ready architecture
- Mobile-first Telegram Mini App UI

## Product direction
Tap & Earn, rewarded ads, daily bonuses, tasks, referrals, leaderboard, rewards and wallet/withdrawal flows.

The project uses **DZE** as the in-app coin symbol.

## Important
Rewards and withdrawals will be configurable and verified server-side. No earning amount is guaranteed until the advertising, backend and payout systems are connected and tested.
